# 止损表（2026-10-16 起草，等用户确认后生效）

## 为什么要有这张表
用户自己说："我担心自己不会割肉止损，一直拿着。"历史证据：
- 10/15 说"那些卖单我不想现在赔钱卖"；
- ORCL 在论点变弱后一直持有；
- VRT 的卖出指令被删掉了；
- MU 亏了 14% 还挂单补仓。

**办法：在情绪平稳的时候，把退出条件写死；触发以后只执行，不讨论。**

## 执行规则
1. **两种退出条件**
   - **论点退出**：事件触发。比如财报、信用事件、关键数据出来时检查。
   - **价格底线**：机械触发。以**周五的周线收盘价**为准，不看盘中价，避免被来回扫掉。
2. **触发后的执行**：下一个交易日 10:00–15:30，用可成交的限价单**全部卖出**。不打折、不分批、不"再等一天"。
3. **禁止的动作**：仓位已经亏损超过 10%，或者价格离止损线不到 5% 时，**不许加仓**，除非事先写好的确认条件已经满足。
4. **每周五收盘后**，我会逐行核对这张表；触发了就用一句话提醒你。
5. 止损线**只能往上调，不能往下调**。只能在周末、通过书面复盘修改。

## 让执行自动化
- 可以在 IBKR 设置价格提醒：周线收盘价无法自动判断，所以提醒设在底线价位，触发后等周五收盘再确认。
- 也可以在 IBKR 里自己挂 GTC 止损单（连接器只能生成限价单和市价单，不能生成止损单）。
